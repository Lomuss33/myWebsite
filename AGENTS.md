# Working in this repository

Read [MAINTANER.md](MAINTANER.md) and [docs/README.md](docs/README.md), then only relevant topic pages. See [active work](docs/work/README.md); archived plans are not current specifications.

- Preserve unrelated changes and accepted visual design.
- Inspect owning source before editing. Content usually lives in `public/data/`; component code and later SCSS can add behavior.
- Read [responsive layout](docs/architecture/responsive-layout.md) for sizing and [Home implementation](docs/architecture/home.md) for Home.
- Edit generated assets through their sources/generators. Use [targeted validation](docs/guides/validation.md), reporting actual scope.
- Update canonical guidance when behavior changes. Scratch belongs in `docs/tmp/`, durable handoffs in `docs/work/`.
- User instructions determine scope. This file grants no deployment permission and adds no mandatory approval step.
