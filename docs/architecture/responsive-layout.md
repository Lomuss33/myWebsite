# Responsive layout

Verified: 2026-09-30 against layout resolution, timeline sizing, digital-expression Art card sources, and Web Art carousel pin lifecycle; not exhaustive device testing.

Mobile navigation has 2px construction-tape stripes on the exposed top of the sticky pill bar and exposed bottom of the fixed tab bar. The sticky placeholder has no tape. Interactive link-state markers use a shared 1px edge: fixed-tab buttons place it at the top, pill buttons at the bottom, and desktop extended/short rail visited buttons at the left. Desktop rail hover bars, outer tape, section separators, resume dividers, and tool-band tape use a 1px width. Active pill buttons use the selected-button mixin's matching bottom highlight.

Decorated sections keep zero bottom padding at desktop density so their page-bottom band reaches the section edge. The desktop page inset applies only to sections without decoration bands. This covers the header-hidden pages and the reordered Art layout through the shared section-content contract.

Headerless decorated pages begin with the top decoration band flush against the scroll pane. Their scroll wrappers do not reserve the 12px fullscreen-control cap above the band, and the wide-portrait mobile inset in [_sizing.scss](../../src/styles/_sizing.scss) applies only to regular sections; neither section nor wrapper top padding may separate the band from the pane edge.

## Mode authority

[responsiveLayout.js](../../src/config/responsiveLayout.js) reads viewport dimensions/root font size and publishes `html[data-layout]`.

| Mode | Rule, in order |
|---|---|
| mobile | Width less than height |
| ultrawide | Otherwise width at least 90rem and width/height at least 2.1 |
| normal | Everything else, including square windows |

Do not introduce independent width-only mobile fallbacks. Container breakpoints may rearrange individual components. Visual viewport keyboard clearance is separate. Update the resolver and boundary tests together.
