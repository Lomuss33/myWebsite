# Historical Software sticker artwork

Archived on 2026-10-05 during sticker-folder cleanup. These files are historical evidence, not current instructions or site assets. All moved files were checked with SHA256 before and after the move; no artwork was deleted.

The archive preserves the previous relative structure so the comparison galleries remain usable:

- 42 PNG masters across the original, neon revision 2 and storytelling revision 3 sets.
- `clean-v4/`: the 14 simpler SVG drawings and their manifest.
- Generation prompts, refinement records, art-direction notes and versioned manifests.
- Original comparison galleries and redundant gallery aliases. `index-modern-v5.html` points to the current shared exports on both backgrounds; its paths were updated after the move and the user's request to remove the light set.
- `manifest-modern-v5.json`: the original version-5 export manifest, retaining the paths before cleanup.
- `responsive/`: 168 unused WebP derivatives from the three superseded PNG sets.
- `generate-clean-v4.js.txt`: the preserved revision-4 generator source, archived as text to prevent accidental regeneration into the current collection.

Current source: [Software sticker generator](../../../../npm/generate-software-stickers.js). Current exports and gallery: [Software stickers](../../../../public/images/stickers/software/README.md). Current ownership: [maintenance](../../../guides/maintenance.md#change-image-handling).

Old commands and paths in the completed work record describe their original locations. Do not run archived generation instructions against the current public folder. New public assets are regenerated only from the current generator.
