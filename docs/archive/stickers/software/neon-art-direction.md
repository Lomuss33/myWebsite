# Software sticker artwork, revision 2

Built-in imagegen edits of the 14 accepted revision-1 illustrations. The precise per-image prompts and input paths are in `prompts-neon-v2.json`; each edit uses one original PNG as its target, rather than inventing a new subject.

## Visual system

- Object interiors: midnight navy `#091326` and graphite `#131E32`, with cool slate secondary planes.
- Primary edge and icon colours: electric cyan `#28E8FF`, cobalt `#4864FF`, ultraviolet `#A14DFF`.
- Meaningful status/suit accents only: mint `#43FFC6` and coral `#FF4E83`.
- Left stickers: solid digital emblems, intentional two-tone surfaces and selective neon edges.
- Right stickers: precision interface linework, dark interiors and controlled luminous paths.
- Every graphic keeps its accepted composition, silhouette, count of objects and negative spaces, with an approximately 90% canvas footprint.
- True alpha transparency outside each object. No opaque background panel or large glow cloud.
- Remove all cream/ivory/yellow-white carriers, grain, print misregistration, distressed outlines, paper texture and decorative dust.
