# OpenDyslexic guide font

Regular and bold WOFF2 files are unmodified upstream exports, hosted locally for
the startup navigation guide in both themes. They do not change the site's other
typography. The regular and bold faces use their actual 400 and 700 weights.

Source: [OpenDyslexic upstream snapshot](https://github.com/antijingoist/opendyslexic/tree/1824da5c0e41dc3e13ffc7f3a636dcaf695d61b7/compiled),
commit `1824da5c0e41dc3e13ffc7f3a636dcaf695d61b7`.

Keep the supplied [SIL Open Font License](OFL.txt) with these files. Update from
upstream exports rather than editing compiled fonts. No external font service is
required at runtime.
