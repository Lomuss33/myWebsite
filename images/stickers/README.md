# Sticker collections

- `software/`: one shared set of 14 SVGs using the former dark palette in both themes, one gallery and one manifest. The app uses the corresponding generated inline SVG artwork.
- `hardware-experiments/`: the 16 installed Hardware PNG masters and their provenance. The existing name and image URLs are retained for compatibility.

Superseded Software drawings, prompts, galleries and unused raster derivatives are preserved outside the published assets in [the historical archive](../../../docs/archive/stickers/software/README.md).

Current editing and regeneration instructions: [maintenance](../../../docs/guides/maintenance.md#change-image-handling).
